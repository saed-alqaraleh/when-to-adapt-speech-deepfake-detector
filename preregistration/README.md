# Pre-registration records

These files record the fixed study decisions for the initial prevalence screen, the ASVspoof 5 guarded-policy test, cross-detector generalisation and subsequent source-aware split audit. Values and hypothesis definitions follow the research execution records.

The original latest protocol is included byte-for-byte. The first prevalence-stage protocol has a public terminology-normalized derivative rather than an unaltered private original. Its source hash and the derivative hash are documented under `provenance/record-scope.json`; the original historical record remains in the private research archive. Do not use the derivative's creation date as evidence that it predates the original experiment.
